# music-wiki (P2)

저장된 mp3 등 음악을 정리하고 LLM 기반 마크다운 위키 페이지로 만드는 서비스.

- **원본(읽기 전용)**: `/mnt/win/memory/음악` — 약 15,300 트랙(mp3 위주, flac 일부), ~169GB
- **산출물**: `/home`에 마크다운 위키(아티스트/앨범/트랙), 경량 저장소(SQLite 또는 프론트매터)
- **연계**: 기존 `~/Obsidian Vault` 활용 가능, P3(LP)와 음악 지식 그래프 공유
- **상태**: 설계 대기 (P1 이후)
- 설계 문서: `docs/superpowers/specs/`
