# music-wiki (P2 + LP 모듈)

음악(mp3 등)과 **LP 컬렉션**을 하나의 지식베이스로 정리하고 LLM 기반 마크다운 위키로 만드는 서비스. (구 P3 "LP"는 이 프로젝트의 **LP 수집 모듈**로 흡수)

## 공유 코어 (`core/`)
- 데이터 모델: **아티스트 / 앨범 / 트랙 / 레이블 / 장르 / 연도**. 앨범에 **소장형태 플래그(디지털 보유 / 바이닐 보유)**.
- 저장: 마크다운 위키 `[[링크]]` + SQLite. **neo4j는 v1 보류**(관계 질의가 실제로 필요해지면 도입).
- 산출물은 ext4 `/home`, 원본 NTFS는 읽기 전용. `~/Obsidian Vault` 연계 가능.

## `ingest/audio/` (P2)
- 원본(읽기전용): `/mnt/win/memory/음악` — 약 15,300 트랙(mp3 위주, flac 일부), ~169GB
- ID3 태그 → 엔티티. 부족 시 MusicBrainz 보강 + LLM 요약/해설 생성.

## `ingest/lp/` (구 P3, 후순위 마일스톤)
- 입력: **선반 한 줄 = 사진 한 장**, 책등(spine)이 세로로 보이는 고해상도 사진(샘플 5472×3648). 샘플: `/mnt/win/memory/음악/lp` (4장).
- 워크플로:
  1. **순서대로(좌→우) 자동 인식** — 비전 LLM이 읽히는 제목을 위치·신뢰도와 함께 추출
  2. **어렵/실패 항목** → 사용자가 **재촬영**(더 적은 장수·또렷하게) 또는 **수동 제목 입력**으로 보완
  3. **정규화** — Discogs/MusicBrainz 매칭(레이블·카탈로그번호 단서 활용)
  4. **mp3 대조** — 인식 앨범을 audio 라이브러리와 매칭해 바이닐/디지털 보유 표기
  5. **사람 검증 UI** — 크롭된 책등 이미지 + 추정 제목 확인/수정 → 위키 확정
- 현실: 또렷한 책등(클래식 등)은 인식률 높고, 얇고 빽빽한 국내반은 낮음 → **부분 카탈로그 + 보완**을 전제로 설계.
